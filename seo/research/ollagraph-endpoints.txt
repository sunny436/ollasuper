==============================
TECHNICAL SEO
==============================

/v1/seo/meta-audit
→ Audits page title, meta description, H1, canonical, robots, viewport, Open Graph, indexability, and soft-404 signals.

/v1/seo/redirect-chain-map
→ Analyzes URL redirect chains and redirect hops.

/v1/seo/broken-links-audit
→ Finds broken links and checks their HTTP status and final URL.

/v1/seo/mixed-content
→ Finds HTTP resources loaded by HTTPS pages.

/v1/intel/headers
→ Analyzes HTTP response headers relevant to technical SEO.

/v1/intel/ssl
→ Checks SSL/HTTPS information for a domain.

/v1/intel/uptime
→ Checks website availability and uptime-related information.

ON-PAGE SEO
